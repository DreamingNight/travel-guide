# 阿里宣传页「核心景点图鉴」设计

## 目标

在不把宣传页扩写成完整路书的前提下，用更多优质图片体现13天路线的自然景观、人文内容和A/B分岔，增强同行招募吸引力。

## 内容范围

保留现有首屏六图精选画廊；在其后增加一组横向滑动的「核心景点图鉴」。图鉴只选以下八组：

1. 拉萨：布达拉宫、大昭寺或八廓街、西藏博物馆。
2. 羊卓雍措：高位湖盆、半山湖湾、沿线农牧景观。
3. 神山与两湖：冈仁波齐晨光、玛旁雍措、拉昂措。
4. A线古格：遗址全景、洞窟或壁画、托林寺。
5. B线山南：桑耶寺、雅鲁藏布江谷、雍布拉康或昌珠寺。
6. G317羌塘：高原公路、湖盆草场、野生动物或牧业日常。
7. 色林措：湖色、岸线、远山台地。
8. 纳木措：湖湾、念青唐古拉山、合规景区湖岸。

每组使用三张图片和一句短介绍。文案用于传达“为什么值得去”，不加入车时、导航、预约和风险说明；这些仍留在完整路书。

## 交互与布局

- 桌面端：横向卡片轨道，单屏展示约2.3张卡；提供左右箭头、滚轮/触控板横移和清晰的当前位置提示。
- 移动端：原生横向滑动，卡片约占视口宽度86%，露出下一张边缘作为滑动提示；使用滚动吸附。
- 每张卡采用“一张主图＋两张副图”的三联画，点击任意图片沿用现有灯箱。
- A线与B线使用不同角标，但视觉权重一致，避免在宣传页暗示已经选定其中一案。
- 尊重 `prefers-reduced-motion`，键盘可聚焦卡片、箭头和图片。

## 图片与来源

- 优先使用现有路书已经下载并核对过的小红书实拍与可再利用的 Wikimedia Commons 图片。
- 每组先按视觉吸引力筛选，再核对地点与可执行性，不因素材已经存在而凑数；同组照片必须在景别、视角或内容上有明显差异。
- 色林措重点选择湖湾曲线、渐变湖色、远山台地三类画面，不再用单一卫星图或三张相似湖面照代替。
- 不使用会暗示非工程化湖岸、无人机、越野支线或转山视角可执行的图片。
- 小红书图片保留作者和原帖链接；公开长期使用前仍建议取得作者授权。
- 所有新增图片转为 WebP，长边不超过1600px，单张目标小于250KB，并启用懒加载。

## 性能与降级

- 图鉴首张可提前加载，其余全部懒加载。
- JavaScript 失效时，卡片仍可原生横向滚动；箭头只是增强功能。
- 图片加载失败时保留卡片标题和背景色，不影响页面其他内容。

## 验收

- 1440×1000 与 375×812 均无横向页面溢出。
- 桌面箭头、触控板及移动端手势均能浏览全部八组。
- 所有24张图片可加载、具备准确替代文本，并能打开和关闭灯箱。
- 页面无控制台错误；新增图片总体积受控。
- 发布后线上HTML及新增资源哈希与本地一致。
